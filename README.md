# Open Bible School

Open Bible School is a Bible literacy assessment app with a Next.js frontend and a Supabase backend.

## Frontend

The active frontend app lives in `web/`.

```bash
cd web
npm install
cp .env.example .env.local
npm run dev
```

Then open `http://localhost:3000`.

## Environment

`web/.env.local` is private and should not be committed. Use `web/.env.example` as the shareable template for collaborators.

## Collaboration

See `web/COLLABORATING.md` for the setup steps to share with another developer.

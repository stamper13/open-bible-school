# Supabase Docs

This directory contains current backend architecture references. Files here are
intended for humans; generated evidence stays under `supabase/review` and
database-executable checks stay under `supabase/verify`.

- `rpc-contracts.md`: app-facing and load-bearing function contract registry.
- `direct-data-access.md`: intentional frontend/server `.from(...)` relation
  usage and review notes.
